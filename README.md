## À propos

Ce dépôt contient un thème WordPress construit à partir de templates PHP classiques : en-tête, pied de page, page d'accueil, pages de contenu et article individuel.

## Fonctionnalités

- structure de thème WordPress ;
- templates PHP réutilisables ;
- feuille de styles personnalisée ;
- pages de contenu et article ;
- page 404 dédiée.

## Installation locale

1. Copier le dossier dans wp-content/themes.
2. Activer le thème depuis l'administration WordPress.
3. Configurer un site WordPress local pour afficher les templates.

## Contexte

Exercice de formation consacré à la structure d'un thème WordPress et à l'intégration PHP/CSS.
